# MemeCraft

A fast, distraction-free meme generator built with vanilla HTML, CSS, and JavaScript. 100% client-side and privacy-friendly.

## Features

- **10 built-in templates**: Drake, Cat Yelling, This is Fine, Disaster Girl, Doge, Mocking Spongebob, Roll Safe, Futurama Fry, Change My Mind, and Buzz Everywhere.
- **Custom images**: Upload an image, drag-and-drop onto the canvas, or paste straight from your clipboard (`Ctrl+V` / `⌘V`).
- **Two layout styles**:
  - **Top & Bottom**: Classic Impact font with black outline.
  - **Header Box**: Modern white caption box above the image.
- **Quick controls**: Real-time preview, font size slider, and uppercase toggle.
- **Fast sharing**: One-click "Copy Image" to clipboard (ready to paste in Discord, Slack, or X) and PNG download.
- **No dependencies**: Pure HTML, CSS, and JS. No trackers, no server uploads.

## Running Locally

Open `index.html` in any web browser, or run a local server:

```sh
python3 -m http.server 8080
```
